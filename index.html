How to install in Gmail
  1. Click Copy signature above.
  2. Open Gmail → Settings (gear icon) → See all settings.
  3. Scroll to the Signature section and click Create new (or pick an existing one).
  4. Paste (⌘V or Ctrl+V) into the signature editor.
  5. Scroll down and click Save Changes.
